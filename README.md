# KnobNext

Android-приложение: переключение треков и видео **кнопками громкости** в любом плеере.

| Действие | Результат |
|---|---|
| Короткое нажатие «+» / «−» | громкость, как обычно |
| Удерживать «+» | следующий трек / видео |
| Удерживать «−» | предыдущий трек / видео |
| «+» и «−» одновременно | пауза / воспроизведение |

Работает с любым приложением, которое поддерживает медиакнопки (как кнопки на Bluetooth-наушниках):
YouTube, YouTube Music, Spotify, Яндекс Музыка, VK Музыка, VLC, браузеры и т. д.

## Установка

**Готовый APK.** Каждый push собирается в GitHub Actions: вкладка **Actions** → последний запуск
«Build APK» → блок **Artifacts** → `KnobNext-apk`. Скачайте архив, распакуйте и установите
`app-release.apk` на телефон (нужно разрешить установку из неизвестных источников).

**Сборка самому.** Откройте папку в Android Studio и нажмите Run, либо выполните:

```bash
./gradlew assembleRelease   # APK: app/build/outputs/apk/release/app-release.apk
```

## Настройка

1. Откройте KnobNext и нажмите «Открыть „Специальные возможности“».
2. Найдите **KnobNext** (иногда в разделе «Скачанные приложения» / «Установленные службы») и включите.
3. **Android 13+:** если переключатель серый и написано «Ограниченная настройка» — это защита
   для приложений, установленных из APK. Откройте «О приложении» → меню **⋮** →
   **«Разрешить ограниченные настройки»** и повторите шаг 2.
4. **Xiaomi / Huawei / Honor / Samsung и др.:** чтобы система не отключала сервис, разрешите
   приложению автозапуск и отключите для него оптимизацию батареи.

## Настройки в приложении

- **Только когда играет звук** (по умолчанию включено) — если ничего не играет, кнопки громкости
  работают полностью штатно. После паузы через KnobNext приложение ещё 5 минут слушает кнопки,
  чтобы можно было снова запустить воспроизведение тем же способом.
- **Поменять направления** — удержание «+» будет включать предыдущий трек.
- **«+» и «−» вместе** — пауза / воспроизведение.
- **Вибрация** при переключении.
- **Длительность удержания** — 250–1500 мс (по умолчанию 500).

## Как это работает

Приложение — это служба специальных возможностей (`AccessibilityService`) с флагом
`flagRequestFilterKeyEvents`. Это единственный способ без root получать нажатия кнопок громкости
поверх любого приложения. Служба видит **только** нажатия кнопок громкости: доступ к содержимому
экрана отключён (`canRetrieveWindowContent="false"`), интернета у приложения нет.

- При нажатии кнопки громкости событие перехватывается и запускается таймер.
- Если кнопку отпустили раньше — громкость меняется на один шаг через `AudioManager`.
- Если удержали дольше порога — через `AudioManager.dispatchMediaKeyEvent()` отправляется
  `MEDIA_NEXT` / `MEDIA_PREVIOUS`. Система передаёт команду активной медиасессии, то есть
  плееру, который сейчас играет.
- Во время звонка кнопки не перехватываются.

## Ограничения

- **При выключенном экране** на большинстве телефонов Android не передаёт нажатия кнопок
  службам специальных возможностей, так что переключение работает при включённом экране
  (в том числе на экране блокировки).
- Пока играет музыка, удержание кнопки переключает трек, поэтому быстро менять громкость
  удержанием нельзя — нужно нажимать несколько раз.
- APK подписывается отладочным ключом, который генерируется при каждой сборке в CI. Перед
  установкой новой версии из Actions удалите старую.
