# KnobNext

Android-приложение: управление музыкой и видео **кнопками громкости** в любом плеере —
при включённом и выключенном экране.

## Жесты

| Жест | Действие по умолчанию |
|---|---|
| Короткое нажатие «+» / «−» | громкость, как обычно |
| Удерживать «+» | следующий трек |
| Удерживать «−» | предыдущий трек |
| «+» и «−» вместе | пауза / воспроизведение |
| Дважды «+» при выключенном экране | следующий трек |
| Дважды «−» при выключенном экране | предыдущий трек |

Каждому жесту можно назначить: следующий / предыдущий трек, паузу, перемотку ±10 с или ничего.
У каждого действия своя вибрация: вперёд — щелчок, назад — двойной, пауза — сильный,
перемотка — тройной.

Работает с любым плеером, который поддерживает медиакнопки: YouTube, YouTube Music, Spotify,
Яндекс Музыка, VK Музыка, VLC, браузеры и т. д.

## Возможности

- **Выключенный экран.** Служба специальных возможностей не получает нажатий при выключенном
  экране, но система всё равно меняет громкость и сообщает об этом. KnobNext ловит два быстрых
  изменения подряд в одну сторону, выполняет действие и возвращает громкость обратно. Удержание
  кнопки (плавная регулировка) распознаётся и не считается жестом. На максимальной и нулевой
  громкости жест в эту сторону не сработает — громкость просто не меняется.
- **Связь с плеером** (по желанию, нужен доступ к уведомлениям): карточка «Сейчас играет»
  с обложкой и кнопками, точная перемотка, выбор плееров, в которых работают жесты,
  возобновление после паузы. Сами уведомления приложение не читает.
- **Только с наушниками** — жесты работают, только когда подключены проводные, Bluetooth
  или USB-наушники.
- **Защита в кармане** — не срабатывать, когда закрыт датчик приближения. Датчик включается
  только на секунду-две вокруг нажатия.
- **Плитка в шторке** быстрых настроек — включить/выключить одним касанием.
- **Проверка обновлений** — приложение сообщает о новом релизе на GitHub.

## Установка

Скачайте `KnobNext-<версия>.apk` со страницы **Releases** и установите (разрешите установку
из неизвестных источников). Новые версии ставятся поверх старых — настройки сохраняются.

Промежуточные сборки есть во вкладке **Actions** → последний запуск → **Artifacts**.

## Настройка

1. Откройте KnobNext → «Включить» → **Специальные возможности → Скачанные приложения →
   KnobNext** → включите.
2. **Android 13+:** если переключатель серый («Ограниченная настройка») — «О приложении» →
   **⋮** → **«Разрешить доступ к настройкам с ограниченным доступом»**, затем повторите шаг 1.
3. По желанию: в карточке «Подключите плеер» нажмите «Дать доступ» и включите
   **KnobNext — управление плеером**.
4. Плитка: опустите шторку → ✏️ → перетащите **KnobNext**.
5. **Xiaomi / Huawei / Honor / Samsung:** разрешите автозапуск и отключите оптимизацию батареи.

## Релизы (для разработчика)

Сборка в GitHub Actions подписывает APK постоянным ключом из секретов репозитория
(**Settings → Secrets and variables → Actions**):

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 |
| `KEYSTORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Без секретов APK подписывается одноразовым отладочным ключом. Выпуск релиза:

```bash
git tag v3.0.0 && git push origin v3.0.0
```

Workflow соберёт APK с версией из тега и опубликует его в Releases. `versionCode` = число
коммитов. Проверка обновлений в приложении работает, только если репозиторий публичный.

Локальная сборка: `./gradlew assembleRelease` (нужны JDK 17+ и Android SDK 37).

## Как это работает

- `KnobService` — служба специальных возможностей с `flagRequestFilterKeyEvents`. При включённом
  экране перехватывает кнопки громкости: короткое нажатие меняет громкость через `AudioManager`,
  удержание и комбинация выполняют действие. При выключенном экране слушает
  `VOLUME_CHANGED_ACTION`. Доступа к содержимому экрана нет.
- `KnobNotificationListener` — пустой слушатель уведомлений. Включённый, он даёт право вызывать
  `MediaSessionManager.getActiveSessions()`, чтобы видеть плеер и управлять им через
  `MediaController`. Без него команды отправляются как медиакнопки.
- Во время звонка кнопки не перехватываются.
