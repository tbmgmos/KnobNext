# KnobNext

Android-приложение: управление музыкой и видео **кнопками громкости** в любом плеере —
при включённом и выключенном экране.

## Жесты

| Жест | Действие по умолчанию |
|---|---|
| Короткое нажатие «+» / «−» | громкость, как обычно |
| Удерживать «+» | следующий трек |
| Удерживать «−» | предыдущий трек |
| «+» и «−» вместе | пауза / воспроизведение |
| Дважды «+» (по выбору: выкл / при выключенном экране / всегда) | следующий трек |
| Дважды «−» (по выбору: выкл / при выключенном экране / всегда) | предыдущий трек |

Каждому жесту можно назначить: следующий / предыдущий трек, в начало трека, паузу, перемотку ±10 с,
громче / тише, озвучить трек (название и исполнитель голосом), «нравится», перемешивание, повтор,
другой плеер, таймер сна (15 / 30 / 60 мин, музыка плавно затихает), открыть плеер, а также
фонарик и переключение звонка «звук / вибрация» — или ничего.
У каждого действия своя вибрация: вперёд — щелчок, назад — двойной, пауза — сильный,
перемотка — тройной.

Работает с любым плеером, который поддерживает медиакнопки: YouTube, YouTube Music, Spotify,
Яндекс Музыка, VK Музыка, VLC, браузеры и т. д.

## Возможности

- **Выключенный экран.** При выключенном экране Android не передаёт нажатия кнопок службам
  специальных возможностей, поэтому удержание там распознать нельзя. Но система меняет громкость
  и сообщает об этом: KnobNext ловит два быстрых изменения подряд в одну сторону (двойное
  нажатие), выполняет действие и возвращает громкость обратно. Режим двойного нажатия выбирается
  в настройках, там же видно последнее распознанное событие. Удержание
  кнопки (плавная регулировка) распознаётся и не считается жестом. На максимальной и нулевой
  громкости жест в эту сторону не сработает — громкость просто не меняется.
- **Связь с плеером** (по желанию, нужен доступ к уведомлениям): карточка «Сейчас играет»
  с обложкой и кнопками, точная перемотка, выбор плееров, в которых работают жесты.
  Сами уведомления приложение не читает.
- **Только когда играет звук** (по умолчанию). Если ничего не играет, удержание кнопок меняет
  громкость как обычно. Чтобы продолжить музыку, нажмите «+» и «−» вместе: первая кнопка
  сработает как обычная громкость, вторая запустит воспроизведение.
- **Только с наушниками** — жесты работают, только когда подключены проводные, Bluetooth
  или USB-наушники.
- **Защита в кармане** — не срабатывать, когда закрыт датчик приближения. Датчик включается
  только на секунду-две вокруг нажатия.
- **Постукивание по задней панели** — своё распознавание по акселерометру (системное «Быстрое
  касание» Pixel сторонним приложениям недоступно и умеет только двойное). Датчик включается,
  только пока играет музыка; касания экрана отсеиваются по направлению толчка.
- **Свои жесты для приложений.** Например, в YouTube и подкастах удержание перематывает,
  а в Spotify переключает треки. Профиль включается сам, когда играет это приложение.
- **Проверка жестов** — экран, на котором жесты только отмечаются (действия не выполняются):
  видно, что распознаётся, а что нет. Можно проверить и жесты при выключенном экране.
- **Плитка в шторке** быстрых настроек — включить/выключить одним касанием.
- **Проверка обновлений** — приложение сообщает о новом релизе на GitHub.

## Установка

Скачайте `KnobNext-<версия>.apk` со страницы
[**Releases**](https://github.com/tbmgmos/KnobNext/releases/latest) и установите (разрешите
установку из неизвестных источников). Новые версии ставятся поверх старых — настройки сохраняются,
а приложение само сообщает о выходе новой версии и обновляется кнопкой «Обновить» — без браузера.

Промежуточные сборки есть во вкладке **Actions** → последний запуск → **Artifacts**.

## Настройка

Откройте KnobNext — карточка «Настройка» проведёт по шагам и сама откроет нужные страницы:

1. **Снять ограничение Android** — только на Android 13+ и только если APK установлен из файла.
   При установке из магазина (RuStore) этого шага нет.
2. **Включить службу KnobNext** — откроется страница именно KnobNext, после включения
   приложение вернётся само.
3. **Подключить плеер** (по желанию) — доступ к уведомлениям для карточки «Сейчас играет»,
   перемотки и выбора плееров.

Плитка: опустите шторку → ✏️ → перетащите **KnobNext**. На Xiaomi / Huawei / Honor / Samsung
может понадобиться разрешить автозапуск и отключить оптимизацию батареи.

## Релизы (для разработчика)

Сборка в GitHub Actions подписывает APK постоянным ключом из секретов репозитория
(**Settings → Secrets and variables → Actions**):

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 |
| `KEYSTORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Без секретов APK подписывается одноразовым отладочным ключом.

Собираются две версии с одним ключом (ставятся одна поверх другой):

- `github` — проверяет обновления в GitHub Releases (разрешение на интернет);
- `rustore` — без проверки обновлений и без доступа к сети. Артефакт `KnobNext-<версия>-rustore`.
  Материалы для публикации: `store/rustore.md`, `store/icon-512.png`, `PRIVACY.md`.

Выпуск релиза:

```bash
git tag v3.0.0 && git push origin v3.0.0
```

Workflow соберёт APK с версией из тега и опубликует его в Releases. `versionCode` = число
коммитов. Проверка обновлений в приложении работает, только если репозиторий публичный.

Локальная сборка: `./gradlew assembleGithubRelease` или `assembleRustoreRelease` (нужны JDK 17+ и Android SDK 37).

## Как это работает

- `KnobService` — служба специальных возможностей с `flagRequestFilterKeyEvents`. При включённом
  экране перехватывает кнопки громкости: короткое нажатие меняет громкость через `AudioManager`,
  удержание и комбинация выполняют действие. При выключенном экране слушает
  `VOLUME_CHANGED_ACTION`. Доступа к содержимому экрана нет.
- `KnobNotificationListener` — пустой слушатель уведомлений. Включённый, он даёт право вызывать
  `MediaSessionManager.getActiveSessions()`, чтобы видеть плеер и управлять им через
  `MediaController`. Без него команды отправляются как медиакнопки.
- Во время звонка кнопки не перехватываются.
