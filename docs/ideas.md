# Отложенные идеи

## Двойное нажатие кнопки питания

**Статус:** отложено (обсуждено, не реализуется).

### Ограничения платформы

- Кнопку питания система обрабатывает до приложений: служба специальных возможностей не получает
  `KEYCODE_POWER`, нажатие нельзя ни увидеть, ни отменить. Удержание (Ассистент / меню питания)
  переназначить нельзя.
- Видно только следствие нажатия — включение/выключение экрана (`ACTION_SCREEN_ON` / `ACTION_SCREEN_OFF`).

### Как можно сделать

- Жест «двойное нажатие питания»: экран выключился и сразу включился (или наоборот) быстрее
  ~0,6 с, и при этом играет музыка → назначаемое действие (например, следующий трек).
- Только пока играет музыка; по умолчанию выключено; порог времени настраиваемый.
- Если жест сработал при выключенном экране — сразу снова погасить экран через службу
  специальных возможностей (`performGlobalAction(GLOBAL_ACTION_LOCK_SCREEN)`), чтобы телефон
  в кармане остался заблокированным.

### Подводные камни

1. На Pixel двойное нажатие питания по умолчанию открывает камеру (или Wallet). Пользователю нужно
   отключить: «Настройки → Система → Жесты → Двойное нажатие кнопки питания». Приложение не может
   прочитать эту настройку (скрытый ключ `Settings.Secure`) — только подсказка.
2. Пять нажатий подряд запускают экстренный вызов (SOS) — поддерживать только двойное нажатие.
3. Ложные срабатывания: быстро включили и выключили экран, чтобы посмотреть время.
4. Задержка доставки событий экрана 0,2–0,5 с — реакция медленнее, чем у кнопок громкости.
5. Экран на мгновение включается — жест не скрытый.
