# Отложенные идеи

## Голос и локальные модели в версии для RuStore

**Статус:** отложено — вернуться после версии для GitHub.

- В сборке `rustore` нет доступа к интернету: скачать локальную модель (LLM) или модель Vosk
  из приложения нельзя.
- Вариант: импорт файла модели вручную (выбор файла через системный диалог, проверка
  контрольной суммы), подсказка, где скачать.
- Gemini Nano и системное распознавание речи работают без сети приложения — их можно оставить.
- Проверить правила RuStore по размеру и разрешениям (`RECORD_AUDIO`, роль ассистента).

## Двойное нажатие кнопки питания

**Статус:** реализовано в 3.0 («Питание дважды»; удержание — через роль цифрового ассистента).

### Ограничения платформы

- Кнопку питания система обрабатывает до приложений: служба специальных возможностей не получает
  `KEYCODE_POWER`, нажатие нельзя ни увидеть, ни отменить. Удержание (Ассистент / меню питания)
  переназначить нельзя.
- Видно только следствие нажатия — включение/выключение экрана (`ACTION_SCREEN_ON` / `ACTION_SCREEN_OFF`).

### Как можно сделать

- Жест «двойное нажатие питания»: экран выключился и сразу включился (или наоборот) быстрее
  ~0,6 с, и при этом играет музыка → назначаемое действие (например, следующий трек).
- Только пока играет музыка; по умолчанию выключено; порог времени настраиваемый.
- Если жест сработал при выключенном экране — сразу снова погасить экран через службу
  специальных возможностей (`performGlobalAction(GLOBAL_ACTION_LOCK_SCREEN)`), чтобы телефон
  в кармане остался заблокированным.

### Подводные камни

1. На Pixel двойное нажатие питания по умолчанию открывает камеру (или Wallet). Пользователю нужно
   отключить: «Настройки → Система → Жесты → Двойное нажатие кнопки питания». Приложение не может
   прочитать эту настройку (скрытый ключ `Settings.Secure`) — только подсказка.
2. Пять нажатий подряд запускают экстренный вызов (SOS) — поддерживать только двойное нажатие.
3. Ложные срабатывания: быстро включили и выключили экран, чтобы посмотреть время.
4. Задержка доставки событий экрана 0,2–0,5 с — реакция медленнее, чем у кнопок громкости.
5. Экран на мгновение включается — жест не скрытый.

## Закладки в подкастах и видео

**Статус:** отложено (концепция обсуждена, не реализуется).

### Идея

Жест «Закладка» запоминает момент в подкасте, аудиокниге или видео (YouTube и т. п.), чтобы потом
вернуться к нему.

- Сохраняется: приложение, название, автор/канал, позиция, длительность, обложка, `METADATA_KEY_MEDIA_ID`
  (если плеер его отдаёт). Позиция — с запасом 10–15 с назад (человек реагирует с опозданием),
  запас настраиваемый.
- Подтверждение — звуковой сигнал, по желанию голосом: «Закладка, 12:34».
- Экран «Закладки»: список по подкастам и эпизодам; к закладке можно добавить заметку, поделиться
  текстом, удалить.
- Возврат к закладке:
  1. тот же эпизод открыт в плеере → `seekTo`;
  2. есть media ID и плеер поддерживает `playFromMediaId` → открыть эпизод и перемотать;
  3. иначе открыть плеер (или поиск по названию) и подсказать время.
- **Автопродолжение по названию:** когда снова заиграло видео/эпизод с закладкой (совпало название
  в том же приложении), предложить уведомлением «Перейти к 12:34?» или перемотать сразу. Обходит
  отсутствие ссылок (YouTube, браузер, VK Видео).
- Жест «К последней закладке».

### Рядом (для подкастов)

- «Повтор 30 с» и «Пропуск рекламы» (60/90 с) — отдельные действия.
- Скорость воспроизведения жестом (1× → 1,25× → 1,5× → 2×) через `setPlaybackSpeed`, если плеер
  поддерживает.
- Таймер сна «до конца эпизода» (длительность известна).
- Шаблон профиля «Подкасты»: удержание ±30 с, «Дважды +» — закладка, «Дважды −» — повтор 30 с,
  тройное «+» — скорость.
- Позже: голосовая заметка к закладке (микрофон, по желанию), экспорт в Markdown, сводка в конце
  эпизода.

### YouTube

- Название, канал и позиция доступны через медиасессию, перемотка (`seekTo`) работает — закладки
  и возврат в открытом видео реальны.
- Неизвестно, отдаёт ли YouTube ID видео. Если да — ссылка с таймкодом `youtu.be/<id>?t=<сек>`;
  если нет — автопродолжение по названию. Проверить первым шагом: закладка пишет в журнал все
  поля метаданных.
- Без YouTube Premium видео ставится на паузу при выключенном экране, поэтому жесты без экрана —
  только с Premium; с включённым экраном работает всё.
- Хранить локально (файл приложения), никуда не отправлять.

## Внешние устройства: наушники, колонки, пульты

Сделано (этап 2 плана): кнопки Bluetooth- и проводных наушников через собственную медиасессию-посредник
(`HeadsetButtons`), переназначение на любые действия, подсчёт нажатий и удержание для устройств,
которые шлют только «пауза / пуск», кнопка ассистента на гарнитуре по выбору. Целевые устройства:
CMF Buds 2 (жесты настраиваются в Nothing X) и Sony WH-1000XM5 (Headphones Connect).

Как работает и что проверить на устройстве:
- Android отправляет кнопки Bluetooth последней активной медиасессии. KnobNext держит свою, пока
  подключены наушники, и копирует в неё состояние плеера, чтобы она оставалась «последней» и наушники
  видели верные название и состояние. Нажатие без назначения уходит плееру как есть.
- Если плеер всё же перехватывает кнопки (журнал не показывает «пришла кнопка …» после нажатия),
  причина в порядке сессий: смотреть приоритет сессии после начала воспроизведения.
- Удержание обычно обрабатывает приложение наушников (Nothing X, Headphones Connect). До KnobNext оно
  доходит, только если там оно отдано голосовому ассистенту.

Не сделано, на потом:
- Проводные гарнитуры и HID-пульты (кольца, клавиатуры) через клавиши службы доступности с режимом
  обучения «нажмите кнопку на устройстве».
- Профили под устройство (по тому, куда идёт звук) и действия при подключении: включить музыку,
  открыть плеер, сменить набор жестов.
- Колонки с Cast, магнитолы, часы.
