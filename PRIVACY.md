# Политика конфиденциальности KnobNext

_Действует с 9 октября 2026 г._

KnobNext — приложение для управления воспроизведением музыки и видео кнопками громкости.
Мы не собираем, не храним на серверах и не передаём третьим лицам персональные данные.

## Какие разрешения использует приложение и зачем

**Служба специальных возможностей (AccessibilityService).** Используется только для того,
чтобы получать нажатия кнопок громкости и отличать короткое нажатие от удержания.
Приложение не получает доступа к содержимому экрана (`canRetrieveWindowContent = false`),
не читает вводимый текст и не выполняет действий от имени пользователя.

**Доступ к уведомлениям (NotificationListenerService), по желанию.** Нужен только для того,
чтобы система разрешила видеть активный медиаплеер (название трека, исполнитель, обложка)
и управлять им (пауза, переключение, перемотка). Содержимое уведомлений приложение не читает.
Сведения о треке показываются только на экране приложения и никуда не передаются.

**Вибрация.** Короткий отклик при выполнении жеста.

**Датчик приближения, по желанию.** Включается на 1–3 секунды при нажатии кнопки, чтобы
не срабатывать в кармане. Данные датчика не сохраняются.

## Какие данные хранятся

Только настройки приложения (выбранные жесты, список плееров, в которых работают жесты).
Они хранятся на устройстве и удаляются вместе с приложением.

## Сеть

Версия из RuStore не использует интернет и не имеет разрешения на доступ к сети.

Версия с GitHub по желанию пользователя проверяет наличие новой версии: отправляет запрос
к `api.github.com`. GitHub при этом получает стандартные сведения о запросе (IP-адрес,
версию Android в заголовке User-Agent). Проверку можно отключить в разделе «О приложении».
