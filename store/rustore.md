## Карточка приложения

**Название:** KnobNext — треки кнопками громкости

**Краткое описание:**
Переключайте треки и видео кнопками громкости в любом плеере

**Категория:** Инструменты (альтернатива — «Музыка и аудио»). **Возраст:** 0+.

**Полное описание:**

KnobNext превращает кнопки громкости в пульт для музыки и видео — в любом приложении:
YouTube, YouTube Music, Яндекс Музыка, VK Музыка, Spotify, VLC, браузеры и другие плееры.

• Удерживайте «+» — следующий трек
• Удерживайте «−» — предыдущий трек
• Нажмите «+» и «−» вместе — пауза / продолжить
• При выключенном экране — двойное нажатие «+» или «−»
• Короткое нажатие меняет громкость, как обычно

Возможности:
• Свои действия для каждого жеста: переключение, пауза, перемотка на 10 секунд
• Карточка «Сейчас играет» с обложкой и кнопками
• Выбор плееров, в которых работают жесты
• Режим «только с наушниками»
• Защита от случайных нажатий в кармане по датчику приближения
• Разная вибрация для разных действий — понятно без взгляда на экран
• Плитка в шторке для быстрого включения и выключения
• Material 3 Expressive, цвета из ваших обоев

Когда ничего не играет, кнопки громкости работают полностью штатно.

Приложение использует службу специальных возможностей только для получения нажатий кнопок
громкости. Оно не видит содержимое экрана, не читает уведомления, не собирает данные и
не использует интернет.

**Что нового (первая версия):**
Управление музыкой кнопками громкости, жесты при выключенном экране, карточка «Сейчас играет»,
настройка жестов, плитка в шторке.

## Декларация разрешений

| Разрешение | Тип | Обоснование |
|---|---|---|
| `BIND_ACCESSIBILITY_SERVICE` | Signature (привязка службы) | Основная функция: получение нажатий кнопок громкости поверх любого приложения, чтобы отличить короткое нажатие (громкость) от удержания (переключение трека). Других способов получить нажатия кнопок громкости в фоне без root в Android нет. Доступ к содержимому экрана отключён (`canRetrieveWindowContent=false`), действия от имени пользователя не выполняются. |
| `BIND_NOTIFICATION_LISTENER_SERVICE` | Signature (привязка службы), по желанию | Нужен для `MediaSessionManager.getActiveSessions()`: показать текущий трек и управлять плеером (пауза, переключение, перемотка), ограничить жесты выбранными плеерами. Из уведомлений используются только кнопки уведомления текущего плеера («нравится», «перемешать», «повтор») — их нажимает жест пользователя. Текст других уведомлений не читается. |
| `BIND_QUICK_SETTINGS_TILE` | Signature (привязка службы) | Плитка в шторке для включения/выключения жестов. |
| `VIBRATE` | Normal | Тактильный отклик при выполнении жеста. |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE` | Normal | Служба переднего плана (тип specialUse) работает, только когда включено двойное нажатие при выключенном экране. Без неё система замораживает процесс и события громкости приходят с опозданием, поэтому жест невозможно распознать. Служба ничего не обрабатывает сама и не использует сеть. |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Normal | Открывает системный диалог «Не ограничивать расход батареи» по нажатию пользователя — нужно для работы жестов при выключенном экране. |

Собираемые данные: **нет**. Передача данных третьим лицам: **нет**. Сеть: **не используется**.

## Обоснование для модерации (если спросят)

KnobNext — утилита управления медиа. Служба специальных возможностей объявлена с флагом
`flagRequestFilterKeyEvents` и получает только события кнопок `KEYCODE_VOLUME_UP` /
`KEYCODE_VOLUME_DOWN`; все остальные события не обрабатываются
(`accessibilityEventTypes` — минимальный набор, `canRetrieveWindowContent=false`).
Перед включением службы приложение показывает пользователю пояснение, что служба используется
только для кнопок громкости и не видит экран. Аналоги в каталоге RuStore используют службу
специальных возможностей для тех же задач.
